## Use as Extension

This repository can be added as an **extension** in MakeCode.

* open [/](/)
* click on **New Project**
* click on **Extensions** under the gearwheel menu
* search for **https://github.com/joseph-xu-unb/unb-tutorials-fork/ior-599-import-probe** and import

## Edit this project

To edit this repository in MakeCode.

* open [/](/)
* click on **Import** then click on **Import URL**
* paste **https://github.com/joseph-xu-unb/unb-tutorials-fork/ior-599-import-probe** and click import
