# UNBDev Board Guide

Reusable activities for the UNBdev.board.

- `catalog.md` — the cards shown in this home-page row.
- `projects/` — one lesson per card.
- `static/` — card and lesson images.
- Maintainer: **to be named before the first publication.**

These are board-feature lessons. A course activity that adds a sequence,
assessment or course-specific explanation belongs in its own collection rather
than here.

The catalog is empty: the lessons it will hold are migrated from the editor
repository. Adding a card before its lesson exists fails validation, by design.
